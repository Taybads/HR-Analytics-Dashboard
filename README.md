# HR Analytics Dashboard

An interactive **HR Analytics Dashboard** built with **Microsoft Power BI** to visualize employee data and support HR-related analysis.

## 📊 Project Overview

This project presents an HR dashboard that transforms employee data into clear and interactive visual insights. The dashboard is designed to help users explore workforce information, employee distribution, job satisfaction, service years, and employee actions such as promotion or retirement.

## 🎯 Objectives

- Analyze employee information using interactive visualizations.
- Provide a clear overview of the workforce.
- Explore employee distribution and service years.
- Analyze job satisfaction levels.
- Identify employees who may be due for promotion or retirement.
- Present HR insights in an easy-to-understand dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- Data Visualization
- Data Analysis
- Interactive Dashboards
- DAX Measures

## 📌 Dashboard Pages

### Home
Provides a general overview of the HR data with key employee indicators and visual summaries.

### Detail
Provides more detailed employee-related analysis, including:
- Employee counts
- Gender distribution
- Job levels
- Service years
- Job satisfaction
- Employee information

### Action
Focuses on employee actions and highlights employees who are:
- Due for promotion
- Not due for promotion
- Recommended for retirement/replacement actions based on the dashboard analysis

## 📈 Key Visualizations

The dashboard includes different Power BI visuals such as:

- KPI / Card visuals
- Bar charts
- Column charts
- Pie charts
- Donut charts
- Employee detail tables
- Interactive page navigation

## 💡 Key Insights

The dashboard makes it easier to:

- Understand the overall employee structure.
- Compare employee groups.
- Identify patterns related to service years and job satisfaction.
- Monitor promotion-related information.
- Review employee data through interactive filters and visuals.
